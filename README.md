# HUFLIT - Web Programming Labs

Bộ bài thực hành HTML theo các tài liệu:

- Web-Lab01a_HTML.docx
- Web-Lab01b_HTML.docx
- Web-Lab01b2_HTML.docx
- Web-Lab01c_HTML.docx

## Cách chạy

Không cần cài thư viện. Mở `index.html` bằng trình duyệt hoặc dùng VS Code + Live Server.

## Cấu trúc

- `tuan01-a/`: HTML cơ bản, công thức SUB/SUP, bảng 1-25.
- `tuan01-b/`: liên kết giữa các trang, hình ảnh, colspan/rowspan, bảng thông tin sinh viên, layout và portfolio.
- `tuan02/`: layout bằng `table`, `div`, và thẻ HTML5.
- `tuan03/`: form đăng nhập, lấy lại mật khẩu, đăng ký và bản nâng cao dùng `table`.

> Ghi chú: Bài báo ở Tuần 01 - Phần A dùng nội dung mẫu tự viết để thực hành đúng các thẻ HTML yêu cầu, tránh sao chép nguyên văn bài báo có bản quyền.
